# Анализатор графа зависимостей Maven

## Общая информация

Дисциплина: Конфигурационное управление  
Вариант: 17  
Язык реализации: Python 3  
Интерфейс: Командная строка (CLI)

## Описание этапов реализации

### Этап 1. Минимальный прототип с конфигурацией
Реализовано CLI-приложение с настраиваемыми параметрами через опции командной строки. Параметры: имя пакета (groupId:artifactId), URL репозитория или путь к тестовому файлу, режим тестирования, версия пакета, максимальная глубина анализа, подстрока для фильтрации. При запуске выводит все параметры в формате ключ-значение. Реализована валидация входных данных: проверка формата пакета, корректности URL, существования тестового файла, положительности глубины. При ошибках программа завершается с соответствующим сообщением.

### Этап 2. Сбор данных
Реализована логика получения прямых зависимостей из Maven-репозитория. Формируется URL к файлу pom.xml на основе groupId, artifactId и версии. Осуществляется HTTP-запрос через urllib.request для скачивания XML. Парсинг выполняется через xml.etree.ElementTree с предварительным удалением namespace-префиксов для упрощения поиска тегов. Извлекаются все прямые зависимости из секции <dependencies>. Результат выводится на экран в формате "groupId:artifactId".

### Этап 3. Основные операции
Построен полный транзитивный граф зависимостей с использованием алгоритма DFS с рекурсией. Реализована корректная обработка циклических зависимостей через множество посещённых узлов. Поддерживается ограничение максимальной глубины анализа. Реализована фильтрация пакетов по подстроке — пакеты, содержащие заданную подстроку, исключаются из графа. Добавлен тестовый режим: вместо HTTP-запросов читается локальный файл с описанием графа в формате "узел: зависимость1 зависимость2". Демонстрация выполнена на тестовом графе с циклами.

### Этап 4. Дополнительные операции
Реализован вывод порядка загрузки зависимостей через топологическую сортировку (пост-порядок DFS). Сначала устанавливаются пакеты, от которых ничего не зависит (листья графа), в конце — корневой пакет. Сравнение с реальным Maven: Maven использует стратегию "nearest-wins" и сплющивает граф, удаляя транзитивные дубликаты. Наш инструмент строит полный транзитивный граф без отсечения дубликатов, поэтому порядок установки может содержать больше пакетов и отличаться от вывода mvn dependency:tree.

## Описание функций модулей

### Модуль src/main.py
- `parse_arguments()`: разбирает аргументы командной строки через argparse, возвращает объект с параметрами
- `validate_args(args)`: проверяет корректность параметров (формат пакета, URL, существование файла, глубина), завершает программу с ошибкой при невалидном вводе
- `print_config(args)`: выводит все параметры в формате ключ-значение для отладки
- `main()`: точка входа приложения, координирует выполнение этапов

### Модуль src/maven_fetcher.py
- `build_pom_url(repo_url, group_id, artifact_id, version)`: формирует URL к файлу pom.xml на Maven-репозитории, заменяя точки в groupId на слеши
- `fetch_xml(url)`: скачивает XML-контент по URL через urllib.request, возвращает None при ошибке
- `strip_namespaces(root)`: удаляет namespace-префиксы из XML-тегов для упрощения парсинга
- `parse_dependencies(xml_content)`: извлекает прямые зависимости из XML, возвращает список строк "groupId:artifactId"
- `get_direct_dependencies(repo_url, package, version)`: главная функция получения зависимостей, координирует формирование URL, загрузку и парсинг

### Модуль src/graph_builder.py
- `parse_test_file(file_path)`: читает тестовый файл и парсит его в словарь смежности (граф)
- `should_skip(package, filter_str)`: проверяет, должен ли пакет быть исключён по фильтру
- `dfs_recursive(graph, node, depth, max_depth, filter_str, visited, graph_out)`: рекурсивный DFS с учётом глубины, циклов и фильтра, строит итоговый граф
- `build_dependency_graph(source, test_mode, max_depth, filter_str)`: строит полный граф зависимостей, поддерживает тестовый и реальный режимы
- `get_install_order(graph, start_node)`: вычисляет порядок установки через пост-порядок DFS (топологическая сортировка)

## Сборка и запуск

### Требования
- Python 3.8+
- Интернет-доступ (для работы с реальным Maven-репозиторием)
- Сторонние библиотеки не требуются (используется только стандартная библиотека)

### Запуск анализатора

```cmd
rem Базовый запуск с выводом конфигурации
run.bat -p "org.springframework:spring-core" -u "https://repo1.maven.org/maven2/" -v "5.3.20" -d 10 -f ""

rem Демонстрация обработки ошибок
run.bat -p "invalid_package" -u "https://repo1.maven.org/maven2/" -v "1.0"
run.bat -p "org.springframework:spring-core" -u "ftp://wrong.url" -v "1.0"
run.bat -p "A" -u "tests\nonexistent.txt" -t -v "1.0"
run.bat -p "org.springframework:spring-core" -u "https://repo1.maven.org/maven2/" -v "1.0" -d 0
run.bat -p "org.springframework:spring-core" -u "https://repo1.maven.org/maven2/" -v ""

rem Обработка несуществующей версии (демонстрация ошибки)
run.bat -p "org.springframework:spring-core" -u "https://repo1.maven.org/maven2/" -v "99.99.99"

rem Полный граф без ограничений (глубина 10, без фильтра)
run.bat -p "A" -u "tests\test_graph.txt" -t -v "1.0" -d 10 -f ""

rem Ограничение глубины до 1 (только прямые зависимости)
run.bat -p "A" -u "tests\test_graph.txt" -t -v "1.0" -d 1 -f ""

rem Фильтрация пакетов, содержащих подстроку "B" (исключает B и его зависимость D)
run.bat -p "A" -u "tests\test_graph.txt" -t -v "1.0" -d 10 -f "B"

rem Фильтрация пакетов, содержащих подстроку "C" (исключает C и его зависимость E)
run.bat -p "A" -u "tests\test_graph.txt" -t -v "1.0" -d 10 -f "C"

rem Комбинирование: глубина 1 и фильтр "B"
run.bat -p "A" -u "tests\test_graph.txt" -t -v "1.0" -d 1 -f "B"
